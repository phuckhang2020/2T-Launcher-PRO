# Changelog

Notable changes to this project are documented here.

## [Unreleased]

- No changes yet.

## [1.1.0] - 2026-10-15

- Add a Windows desktop rebuild with an NSIS installer and portable ZIP package.
- Add category-first navigation, English/Vietnamese UI, pane/dropdown category views, and drag-reordering.
- Add local file/folder/AHK management, bulk selection and deletion, and double-click to open or run.
- Keep entries in the All view when their category is deleted; protect All from deletion.
- Add AutoHotkey readiness guidance, run/pause status, activity history, and CPU/memory/GPU footer metrics.
- Add desktop settings, GitHub release checks, and hide background console windows.

## [1.0.0] - 2026-10-09

- Prepare the initial public launcher release.
- Add launcher entry search, category filtering, and management.
- Add support for launching AutoHotkey scripts and opening file or folder shortcuts.
- Add theme and global hotkey settings.
- Keep runtime configuration and activity logs local to the user's machine.
